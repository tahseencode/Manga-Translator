# OCR - ONNX-based, no PyTorch. Keeps the serverless bundle well under
# Vercel's 500 MB function size limit (torch + easyocr alone were ~1 GB).
# Default PP-OCRv6 small det/rec models are bundled inside the wheel and
# the v6 small recognition model supports Japanese.

onnxruntime

# rapidocr's metadata pulls in the non-headless opencv-python, which needs
# libGL.so.1 (not present on Vercel/Lambda) and fails at import time.
# Installing opencv-python-headless AFTER rapidocr makes its cv2 build win,
# keeping the deployment serverless-safe. Do not reorder these lines.
